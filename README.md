This repository contains my Day 11 practical laboratory work for the Generative AI for Business course as a BBA Aviation Management student. The lab focuses on using Canva and Canva Magic Studio to create a consistent aviation mini-campaign while evaluating the designs for accuracy, branding, professionalism and responsible AI use.

The activity uses a fictional AeroVista Airports campaign called “Travel Smart at the Airport,” designed to encourage domestic passengers to arrive prepared and follow verified airport instructions. The project includes creating a brand guide with selected colours, fonts, visual style and tone, followed by generating an aviation visual using Magic Media.

The lab demonstrates the use of Magic Expand to adapt an image into another layout and Magic Edit to modify selected visual elements. Each generated design is checked for inaccurate text, false information, unauthorised logos, personal data, unsafe behaviour and misleading aviation details.

Three campaign formats are created: a square social-media post, a portrait passenger-awareness poster and a landscape presentation visual. Brand consistency is maintained across all formats through common colours, fonts, campaign messaging and visual style.

The project also includes a brand-and-accuracy audit, resizing checks, an original aviation mini-campaign, peer review, revisions and reflection. Overall, the lab demonstrates practical AI-assisted design skills while emphasising accuracy, privacy, responsible use and human review before publication.
